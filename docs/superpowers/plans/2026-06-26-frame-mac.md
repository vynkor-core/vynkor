# Frame MAC (T-06) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-connection HMAC-SHA256 frame authentication to the Veyron IPC protocol, active whenever `jwt_secret` is configured.

**Architecture:** A pure crypto module (`frame_mac`) provides HKDF key derivation and HMAC compute/verify. Framing learns to read/write a 32-byte tag gated by a `flags` bit. Each connection's read loop verifies inbound tags (bad tag → immediate connection drop); each connection's write loop appends tags. The router derives the per-connection key on successful JWT registration, returns a random nonce in the ack, and enables MAC on the connection via an ordered control item so the ack itself stays un-tagged. The Rust SDK mirrors the same `frame_mac` logic.

**Tech Stack:** Rust, Tokio, prost/protobuf, RustCrypto (`hmac`, `sha2`, `hkdf`), `rand`.

## Global Constraints

- MAC algorithm: **HMAC-SHA256**, full **32-byte** tag. Copied verbatim from spec.
- Key derivation: `HKDF-SHA256(ikm = jwt_secret_bytes, salt = session_nonce, info = "veyron-frame-mac-v1|" + plugin_id)`, 32-byte output.
- `session_nonce`: **16 random bytes**, generated by the kernel per registration, returned in `PluginRegisterAck.session_nonce` (proto field 4).
- Flag bit: `MAC_PRESENT = 0x0001` in the frame `flags` field.
- Tag covers `header[0..44] || payload`; the tag is **excluded** from the header `length` field. CRC-32 is retained, computed over the payload as today.
- `MAX_PAYLOAD_SIZE` (1 MiB) continues to bound the payload; a MAC'd frame is `length + 32` bytes on the wire.
- MAC is active **only** when `jwt_secret` is set. Under `allow_no_auth`, all frames stay `MAC_PRESENT = 0` (unchanged).
- A registered connection sending a frame with a **bad tag** → `ErrMacInvalid`, **immediate connection drop** (bypasses the per-connection error budget). A registered connection sending `MAC_PRESENT = 0` when secured → `ErrMacMissing`.
- Spec: `docs/superpowers/specs/2026-06-26-frame-mac-design.md`.

```rust
/// Derive the per-connection MAC key. Inputs are known to both the kernel and
/// the plugin: the shared `jwt_secret`, the per-registration `nonce` from the
/// ack, and the registered `plugin_id`.
pub fn derive_session_key(jwt_secret: &[u8], nonce: &[u8], plugin_id: &str) -> [u8; 32] {
    let hk = Hkdf::<Sha256>::new(Some(nonce), jwt_secret);
    let mut info = b"veyron-frame-mac-v1|".to_vec();
    info.extend_from_slice(plugin_id.as_bytes());
    let mut okm = [0u8; 32];
    // HKDF-SHA256 expand of 32 bytes never exceeds the length limit -> safe.
    hk.expand(&info, &mut okm)
        .expect("HKDF expand of 32 bytes is always valid");
    okm
}

/// HMAC-SHA256 over `header || payload`.
pub fn compute_tag(key: &[u8; 32], header: &[u8], payload: &[u8]) -> [u8; MAC_TAG_LEN] {
    let mut mac = HmacSha256::new_from_slice(key).expect("HMAC accepts any key length");
    mac.update(header);
    mac.update(payload);
    let out = mac.finalize().into_bytes();
    let mut tag = [0u8; MAC_TAG_LEN];
    tag.copy_from_slice(&out);
    tag
}

/// Constant-time verification of a tag over `header || payload`.
pub fn verify_tag(key: &[u8; 32], header: &[u8], payload: &[u8], tag: &[u8]) -> bool {
    let mut mac = HmacSha256::new_from_slice(key).expect("HMAC accepts any key length");
    mac.update(header);
    mac.update(payload);
    mac.verify_slice(tag).is_ok()
}
```

Add `pub mod frame_mac;` to `src/auth/mod.rs`.

Replace `write_loop` with:

```rust
async fn write_loop(mut write_half: OwnedWriteHalf, mut rx: mpsc::Receiver<Outbound>) {
    let mut key: Option<[u8; 32]> = None;
    while let Some(item) = rx.recv().await {
        match item {
            Outbound::EnableMac(k) => key = Some(k),
            Outbound::Frame(frame) => {
                let mut frame = *frame;
                if let Some(k) = &key {
                    // Tag outbound frames once MAC is enabled for this connection.
                    frame.flags |= FLAG_MAC_PRESENT;
                    let header = serialize_header(&frame);
                    frame.mac = Some(compute_tag(k, &header, &frame.payload));
                }
                match write_frame_raw(&mut write_half, &frame).await {
                    Ok(()) => {}
                    Err(VeyronError::PayloadTooLarge(n)) => {
                        warn!(bytes = n, "dropping oversized outbound frame");
                        counter!("ipc_frame_errors_total", "error" => "oversized_outbound")
                            .increment(1);
                    }
                    Err(_) => break,
                }
            }
        }
    }
}
```

Add a header-serialization helper (mirrors `write_frame_raw`'s header bytes) so the tag is computed over the exact 44 header bytes that go on the wire:

```rust
fn serialize_header(frame: &Frame) -> [u8; 44] {
    let mut header = [0u8; 44];
    header[0..2].copy_from_slice(&frame.magic.to_be_bytes());
    header[2..4].copy_from_slice(&frame.flags.to_be_bytes());
    header[4..8].copy_from_slice(&frame.length.to_be_bytes());
    header[8..40].copy_from_slice(&frame.target);
    header[40..44].copy_from_slice(&frame.crc32.to_be_bytes());
    header
}
```
